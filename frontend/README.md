# AI Learning Frontend

ReactJS + TypeScript UI for the streaming chat exercise.

## Setup

```powershell
cd frontend
npm install
```

## Run

Start the backend first:

```powershell
cd ../backend
npm run build
npm start
```

Then start the frontend in another terminal:

```powershell
cd ../frontend
npm run dev
```

Open <http://127.0.0.1:5173>.

## Verify

```powershell
npm run typecheck
npm test
npm run build
```
